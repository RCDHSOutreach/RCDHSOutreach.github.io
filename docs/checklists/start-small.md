# Checklist: Start small

Start Small is a checklist of the essential items for any first program. It works with any activity type, so you can start with what you have.

We **strongly** recommend that first-time organizers look for existing outreach programs on their campus. You may be able to add an HPC track to an existing summer program and use the resources and structure already in place. 

## Outreach Examples

Below is a list of simple outreach activities you can do that require minimal staffing, funding, and preparation time. These are a great starting point to build up interest and target 

- Showcasing your computing resources or the type of research you support at a STEAM night table
- Hosting a tour of your data center

# Topics for educational activities

## By Program Type

### Start small
??? "Checklist Items"
	<div class="checklist-item-details" markdown>
	#### Choose hands-on, interactive activities over lecture {#START_SMALL_TOP-01}
	**Example**: Take apart old servers, Raspberry Pi projects, VR activities, robot dogs
	</div>
	---
	
	<div class="checklist-item-details" markdown>
	#### Set a learning goal for each activity, then fit the topic to it {#START_SMALL_TOP-02}
	**Example**: If the goal is to learn to be a scientist, build a project step by step; if it is career exposure, plan a field trip
	</div>
	---
	
	<div class="checklist-item-details" markdown>
	#### Build the curriculum around a faculty or staff member who is excited about the topic {#START_SMALL_TOP-03}
	**Example**: Find the person first, then build the curriculum around them
	</div>
	---
	
	<div class="checklist-item-details" markdown>
	#### Adapt existing lectures and materials for high schoolers {#START_SMALL_TOP-04}
	**Example**: Use what faculty already have, but tweak it for the age group and keep it less intense
	</div>
	---
	
	<div class="checklist-item-details" markdown>
	#### If no faculty member is teaching, ask one to suggest, teach, or check your materials {#START_SMALL_TOP-05}
	**Example**: Or build an HPC demo with some relevance to a field
	</div>
	---
	
	<div class="checklist-item-details" markdown>
	#### Connect what students learn to careers {#START_SMALL_TOP-10}
	**Example**: Field trips, career talks, and showing a pathway beyond a four-year degree
	</div>
	---
